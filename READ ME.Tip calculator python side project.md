Tip calculator(Intro):
    Tip calculator is a python program that is wasn’t difficult to come up with a solutions. It calculates tips depending on the number of people, tip percentage and a bill amount. 

Tech stack:
Python backend programming

Key features:
User input,
Basic calculations,
Implicit joining of long strings with new line characters

Build process:
It always begins with a simple idea and then a flow chart to have the functionality grounded down before complexity. The outputs of the above inputs are to find the Tip amount, Total amount, Tip per person and Total per person. I then moved to defining variables that contain user information followed by necessary calculations and then displaying the output.
The first necessary calculation i began with is how to find the tip amount, divide the percentage tip by 100 and then multiply by the bill amount.
The total amount was found by adding the tip amount and the bill amount. Then the tip per person was found by dividing the Tip amount with the number of people and similary the Total per person was found by diving the total amount by the number of people.
With all the necessary calculations in place, it came to now displaying them with one print statement, some f strings and newline characters.
Lessons learned:
Some times i truly do overthink something simple and its good to notice that you are overthinking it. Clean and formatted code always wins to complicated, repeated and unformatted code even if they have the same output from an input they both used(yes, im talking about defining unnecessary functions that dont even need parameter.
Areas for improvement:
I think i should find a way on how to handle a program without the use of too many variables ,perhaps a function or some data type that can help organize.
